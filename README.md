# Weather App ☀️🌧️

A modern, responsive weather application built with React that provides real-time weather information for any location worldwide. Get instant access to current weather conditions, forecasts, and detailed meteorological data.

## 🚀 Live Demo

[View Live Demo](https://weather-app-1rvx4.onrender.com)

## ✨ Features

- **Real-Time Weather Data** - Fetches current weather information using weather API
- **Location Search** - Search for weather by city name or location
- **Detailed Forecasts** - View temperature, humidity, wind speed, and weather conditions
- **Responsive Design** - Optimized for all screen sizes and devices
- **Clean UI** - Intuitive and modern user interface
- **Dynamic Backgrounds** - Weather-based visual themes

## 🛠️ Technologies Used

- **React.js** - Frontend framework
- **JavaScript (ES6+)** - Core programming language
- **CSS3** - Styling and animations
- **Weather API** - Real-time weather data
- **Vite** - Build tool and development server

## 💻 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Himanshu4754/Weather-App.git
```

2. Navigate to the project directory:
```bash
cd Weather-App
```

3. Install dependencies:
```bash
npm install
```

4. Create a `.env` file in the root directory and add your weather API key:
```
VITE_WEATHER_API_KEY=your_api_key_here
```

5. Start the development server:
```bash
npm run dev
```

6. Open your browser and visit `http://localhost:5173`

## 🔧 Available Scripts

- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
